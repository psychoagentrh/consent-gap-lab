# Consent Gap Lab

Decision, 2026-09-30: build a zero-wallet educational probe of crypto consent gaps. A visitor sees the same fictional “Approve 20 TEST” button under two different simulated permissions, predicts whether the approval could cover more than 20 TEST, and receives an explicit comparison and shareable result URL. A real wallet is never requested. A person learning approvals can finish in under 90 seconds.

The useful mechanism is comparison of button language to permission scope, not autonomous testing in general. The connected portable Flow now reads an owned synthetic JSON specimen over HTTP, validates its schema and expected permission, and returns a timestamped verdict and payload digest. This is an owner-controlled orchestration spike, not browser automation. **UiPath Cloud execution remains unproved until an actual owner-run receipt exists.** UiPath provides the independent, revision-bound observation path; the public teaching interaction does not depend on Cloud availability. Later work can add opt-in UI journeys without misrepresenting this JSON spike as a wallet test.

Rejected for now: generic crypto browser journey runner (Synpress and Well Tested already cover much of testing and evidence); autonomous bug-fixing agent (Gauntlet, SpectreAI and FlakeWarden cover adjacent terrain, with too much uncontrolled surface); agent-verification scoreboard (AgentTrial already publishes sealed trials and receipts). The selected consent-specific question has a clearer public interaction and lower risk, but the UiPath component still needs a real spike before a UiPath-powered claim is credible.

Scope: synthetic data, no account credentials, no transactions, no visitor-triggered Cloud runs. Suggested cases via GitHub issues are editorial feedback, never a work queue. No UiPath endorsement. No guarantee a simulated finding reflects real application behavior. If a real run is later published, show timestamp, source revision, redaction method and uncertainty; do not publish raw tenant traces. Revisit the concept if real visitors do not find the comparison useful.
