The four-node UiPath path

Open each step to follow one observation from input to output. These controls only expand text. They never submit a job.

1 / Manual trigger: choose a specimen

The owner supplies specimenCase: unlimited or bounded. The published gateway manifest restricts inputs to those two cases. The portable Flow itself is not a general-purpose URL scanner.

Public visitors do not use this trigger. Reading this walkthrough or suggesting a case cannot start a Cloud job.

2 / HTTP GET: read the owned fixture

UiPath's managed HTTP action reads https://psycho-product.fly.dev/api/specimens/ plus the chosen case. The response is an invented approval specimen, not a wallet screenshot or live transaction.

The HTTP node has a 30-second timeout and zero retries. A request failure is a failed run, not a substituted success.

3 / Script: reject unexpected data

The evaluator checks the synthetic schema, selected case, known button text, permission fields and digest format. It rejects unexpected data rather than fabricating an observation.

It derives whether allowance exceeds the 20 TEST button and returns approvalIsSwap=false. It does not independently recompute or authenticate the host-provided digest.

4 / End: return eight bounded outputs

The result contains specimenCaseObserved, scopeExceedsButton, approvalIsSwap, verdict, fixtureSchema, payloadDigest, observedAt and method.

Each observation has its own UTC timestamp. The separately published evidence names the tested workspace and immutable public source revisions. Older observations are not live guarantees.

Useful proof. Narrow scope.

UiPath supplies the owner-controlled HTTP JSON observation path. It did not drive a browser, connect a wallet, audit a token or execute a swap. The newer local comparison and calldata inspector are not proved by the two historical runs.

The redacted evidence is a manually curated, unsigned publication. A local digest match links bytes; it does not authenticate a Cloud job or declare a request safe. Visitor-triggered UiPath Cloud runs remain disabled.
